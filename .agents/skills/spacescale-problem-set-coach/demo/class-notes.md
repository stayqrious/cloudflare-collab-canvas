# Class notes: order of operations (Year 7)

We use BIDMAS: Brackets, Indices, Division and Multiplication, Addition and
Subtraction. Division and multiplication are one rank and go left to right.
Addition and subtraction are one rank and go left to right.

The two mistakes we talked about in class:

- Adding before multiplying, as in \(3 + 4 \times 2 = 14\).
- Doing the last operation first when the ranks are equal, as in
  \(12 - 5 + 3 = 4\) or \(20 \div 4 \times 5 = 1\).

For negative numbers we use the number line: start at the first number, move
right for plus, left for minus.
