# Problem set: order of operations

| # | Problem | Answer | Common wrong answer and why |
| --- | --- | --- | --- |
| 1 | \(3 + 4 \times 2\) | 11 | 14: added first |
| 2 | \(12 - 5 + 3\) | 10 | 4: did \(5 + 3\) first |
| 3 | \((8 - 3)^2\) | 25 | 10: read the power as \(\times 2\) |
| 4 | \(-4 + 9\) | 5 | \(-5\): moved left on the number line |
| 5 | \(20 \div 4 \times 5\) | 25 | 1: did \(4 \times 5\) first |

Fast-finisher question, for anyone with all five right:

> Put one pair of brackets into \(3 + 4 \times 2 - 1\) to make it equal 13.

(Answer: \((3 + 4) \times 2 - 1 = 13\). Do not give it.)
